# 学习通 AI 助手隐私政策

扩展在用户访问支持的课程页面时读取题目、选项、视频状态与页面结构。启用 AI 功能后，题目和选项会发送到用户配置的 DeepSeek 或其他 HTTPS API 服务，API Key 随请求发往该服务以完成认证。开启自动答题时，请求可能自动触发。

配置、API Key、答案缓存及字体映射缓存保存在浏览器扩展的本地存储中，不使用浏览器同步。API Key 为本地明文存储。运行日志保留在页面运行内存中。开发者不提供收集服务器，不添加统计分析。卸载扩展可删除扩展本地数据。

题目字体解析可能访问 www.forestpolice.org 获取字体映射表，服务方会收到正常网络请求信息（例如 IP 地址）。第三方服务的数据处理以其隐私政策为准。

支持站点范围包含 chaoxing.com、edu.cn、nbdlib.cn、hnsyu.net 和 gdhkmooc.com 的子域名。自定义 API 域名由用户单独授权。扩展不主动上传浏览器历史、登录密码或登录 Cookie。
